## Supported versions

Security fixes are applied to the current `main` branch. Earlier commits and forks are not
maintained as separate supported versions.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use
[GitHub private vulnerability reporting](https://github.com/nd4ever/azure-vm-disk-observability/security/advisories/new)
to share the affected component, reproduction steps, impact, and any suggested mitigation.
Remove tenant, subscription, resource, customer, and credential information from the
report whenever possible.

The maintainers will review the report, coordinate remediation, and publish an advisory
when appropriate.
